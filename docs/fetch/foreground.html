FetchForeground.kt

Is a Fetch screen open?

Android 12 and later will not let a background service pop a dialog. This counter is how the clipboard watcher chooses a dialog or a notification.

FetchForeground.kt · lines 1–20

Depth

Queue, composer, settings, and folder each call enter in onStart and leave in onStop. open is true while the depth is at least one. OfferActivity does not count itself, so the dialog is not treated as the reason to show another dialog.

package com.miaadrajabi.fetch

/**
 * How many Fetch screens are visible. Clipboard offers use this to decide
 * between a dialog and a notification.
 */
object FetchForeground {
    private var depth = 0

    val open: Boolean
        get() = depth > 0

    fun enter() {
        depth += 1
    }

    fun leave() {
        if (depth > 0) depth -= 1
    }
}
