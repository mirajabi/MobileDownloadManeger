The screen is a saved config

Nothing here downloads a file. Save writes fetch_engine. The next enqueue reads it. A missing file uses these defaults.

Defaults

Four chunks, parallel on, 256 KB minimum piece, five attempts, installer off, checksum and APK structure on, content type and signature off. watchClipboard is a Fetch flag, not a library flag. useAlarm chooses AlarmManager. False means WorkManager.

Where the file may land

Auto lets the library pick a writable directory. Scoped uses the folder name under app storage. Custom is accepted only when the text starts with /. A bare name such as Fetch becomes Auto, because File("Fetch") would resolve to /Fetch and fail before any byte moved.

    fun destinations(): List<DownloadDestination> {
        val trimmed = folder.trim()
        return when (destination) {
            DEST_SCOPED -> listOf(DownloadDestination.Scoped(if (trimmed.isBlank()) "Fetch" else trimmed))
            DEST_CUSTOM -> {
                // A bare name such as "Fetch" is not a folder. File("Fetch") becomes /Fetch.
                if (trimmed.startsWith("/")) listOf(DownloadDestination.Custom(trimmed))
                else listOf(DownloadDestination.Auto)
            }
            else -> listOf(DownloadDestination.Auto)
        }
    }
