# Fetch, the app

This is the Markdown door into the Fetch sample. The designed pages, with the explanation beside each file, are the [Fetch guide](https://mirajabi.github.io/MobileDownloadManeger/fetch/). Open a row here if you want to stay in the repository.

The library calls themselves are the [SDK guide](https://mirajabi.github.io/MobileDownloadManeger/#ch-call) and the [SDK chapters](../README.md).

| File | What it is | Page |
|------|------------|------|
| AndroidManifest.xml | What the system is allowed to start | [Manifest](manifest.html) |
| FetchApp.kt | Load the queue and configure the service | [FetchApp](fetch-app.html) |
| EngineSettings.kt | Every switch, saved on the device | [Engine](engine.html) |
| DownloadDesk.kt | The only calls into the library | [Desk](desk.html) |
| LinkParser.kt | Paste and share become URLs | [Links](links.html) |
| ComposerActivity.kt | New download, range, checksum, clock | [Composer](composer.html) |
| QueueActivity.kt | Pause, resume, copy, move, rename | [Queue](queue.html) |
| QueueAdapter.kt | Which button a row shows | [Adapter](adapter.html) |
| Transfer.kt | The row object | [Transfer](transfer.html) |
| TransferStore.kt | Listener callbacks become rows | [Store](store.html) |
| SavedFiles.kt | Copy bytes and read the new path | [Saved files](saved-files.html) |
| FolderActivity.kt | List a directory Fetch can see | [Folder](folder.html) |
| SettingsActivity.kt | Save the engine, mail, GitHub | [Settings](settings.html) |
| FetchForeground.kt | Is a Fetch screen in front? | [Foreground](foreground.html) |
| ClipOffer.kt | Offer a copied link once | [Clip offer](clip-offer.html) |
| ClipWatchService.kt | Dialog in front, notification behind | [Clip watch](clip-watch.html) |
| OfferActivity.kt | Start this download? | [Offer](offer.html) |
| FetchWidget.kt | A glance on the home screen | [Widget](widget.html) |
| colors.xml | Colors and the list animation | [Theme](look.html) |
