BUILT IN THE OPEN

Kotlin at the core.
Compose on the desktop.

The independent KMP build shares the Span transfer engine. Desktop uses Compose, with JavaFX for inline media. The Android SDK and sample app keep their own documentation.

Explore the architecture and build guide ↗
From the repository root · JDK 17
cd multiplatform
python3 tools/media/prepare.py
./gradlew :desktopApp:run

# Build on the target OS
./gradlew :desktopApp:packageDistributionForCurrentOS

The README covers Android SDK setup, platform requirements and bundled-tool licenses.
